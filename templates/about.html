about the project

Built to teach, not exploit

CyberPort Scanner exists to make TCP/IP networking and port-scanning fundamentals approachable, visual, and safe to practice — the same core technique used by tools like Nmap, distilled for learning.

methodology

How a scan works

01 / RESOLVE

The target hostname or IPv4 address is validated, then resolved to an IP using standard DNS lookups.

02 / CONNECT

For each port in range, a TCP connect-scan attempts a full three-way handshake using Python's socket module — no packet crafting or exploitation involved.

03 / REPORT

Successful connections are marked open and labeled with their common service name, then logged to your secure database for your scan history.

responsible use

Ethics & Legal Guidelines

Scan only what you're authorized to scan

Port scanning systems you don't own or lack written permission to test can violate laws such as the U.S. Computer Fraud and Abuse Act, the UK Computer Misuse Act, and equivalent statutes elsewhere. Always obtain explicit authorization before testing any system that isn't yours.

  • Your own devices, home lab, or personal VPS
  • Systems covered by a signed penetration-testing agreement
  • Purpose-built practice targets (e.g. dedicated CTF ranges)

Built for learning, not offense

This project intentionally implements only a basic TCP connect scan and stops there — no service exploitation, no vulnerability scanning, no payload delivery. It's meant to be a clear, readable codebase for students studying networking, Flask, or full-stack development.
