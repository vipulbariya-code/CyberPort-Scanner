Error Codes & Response Specification

All API responses follow a uniform JSON schema. Client errors and server rejections return "success": false with a structured error object containing an application-specific code and human-readable message.

HTTP Status Error Code Description
400 Bad Request INVALID_TARGET Target address is missing, malformed, or has an invalid hostname/IPv4 format.
400 Bad Request INVALID_PORTS Ports must be positive integers between 1 and 65535, with start <= end.
400 Bad Request PORT_RANGE_TOO_LARGE Scans are capped at a maximum of 1024 ports per request.
400 Bad Request TARGET_NOT_ALLOWED Target resolves to a public or restricted IP under PRIVATE_TARGETS_ONLY=true.
401 Unauthorized UNAUTHORIZED Missing or malformed Authorization header. Use Authorization: Bearer <KEY>.
401 Unauthorized INVALID_API_KEY The provided API key does not exist or failed hash verification.
401 Unauthorized REVOKED_API_KEY The API key has been revoked by the owner and can no longer be used.
404 Not Found SCAN_NOT_FOUND Scan ID does not exist or does not belong to the authenticated user (strict IDOR protection).
429 Too Many Requests RATE_LIMIT_EXCEEDED Per-minute request limit exceeded. Wait before retrying.
429 Too Many Requests CONCURRENT_SCAN_LIMIT User has reached the maximum of 2 concurrent ongoing scans.
